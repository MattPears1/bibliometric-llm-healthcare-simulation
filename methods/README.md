# Methods and chronology

SCREENING_CODEBOOK.md is the eligibility codebook applied by both production review streams. The dated analysis specification and model-review protocol document the original workflow. Resource 2 contains the frozen comparison manifests and public decision ledgers; Resource 6 distinguishes the recovered agent Pilot from actual lead-author checks.

Dated protocols describe intended procedures, including proposed additional reviewers. They are not evidence that every intended step occurred. Only one lead author performed the reported human checks; the planned second-human resolution of the original 15 disagreements was not completed.

Both production streams applied the same eligibility codebook. Direct include/exclude disagreements total 477 across 3,919 records. No claim that reviewers were assigned lenient and strict roles is made in the current release.

The original Pilot protocol amendment is retained in Resource 6 section 1. The current package supersedes earlier counts while preserving the original analytical chronology.
