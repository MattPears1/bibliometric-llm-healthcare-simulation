# Audit records

PUBLIC_RELEASE_FREEZE_V3.json identifies the frozen 483-study authority and separates later human checks.
SOURCE_LINEAGE.csv records source and public hashes for exported files. Original private filesystem locations are not disclosed. Where a later editorial or privacy change modifies an export, its public hash is refreshed and the operation records the change.
SHA256SUMS.csv at the repository root covers every public file except itself; each resource has a local contents ledger.

Source hashes establish file identity, not independent scientific validation. Human-check differences, uncertainties and incomplete rationale fields are reported explicitly in Resource 6.
