# Online Resource 4. Phrases and non-technical skills

This resource supplies the 34 predefined phrase groups, complete frequencies, per-study indicators for all 483 studies, co-occurrence data and the conditional network. The NTS classification codebook and nine-domain outputs distinguish classification from phrase matching.

The fine-grained NTS concept set has 78 concepts and 303 variants. It was applied to 483 titles and 447 available abstracts. The assignments, concept summary, thesaurus and displayed-concept co-occurrence matrix are included. A phrase match describes text, not demonstrated skill performance or educational effectiveness.

Historical filenames beginning FIGURE_S1 identify the same fine-grained NTS artwork used as current article Figure 5; current Figures 1–7 and captions are in the repository results/figures directory. Resource artwork is unchanged from the approved source files.

No full abstracts, source-keyword text or downloaded full texts are redistributed. The released indicator tables permit inspection and aggregation without reproducing that text.
