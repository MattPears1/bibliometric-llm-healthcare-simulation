# Online Resource 4: predefined phrases and conditional network

Thirty-four meaningful phrase groups and exact variants were fixed before counting. Titles, retained abstracts, and source keywords were searched. Each phrase was counted at most once per study in each field; any-field counts are unions, not sums.

The per-study indicator ledger, phrase frequencies, co-occurrence table, node ledger, and edge ledger permit independent reconstruction. In the conditional network, node area represents phrase-level study count and line width represents joint study count. The layout is descriptive rather than inferential.
