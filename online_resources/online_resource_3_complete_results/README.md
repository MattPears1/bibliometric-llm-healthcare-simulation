# Online Resource 3. Complete results

This resource contains complete annual, citation, source, geography, author, simulation, specialty, study-design and sensitivity tables for the frozen 483-study corpus.

CORRECTED_MODEL_FAMILY_COUNTS_N483.csv and MODEL_IDENTITY_COVERAGE_N483.csv are the current model-family authority. Families are non-exclusive. A named family was established for 317 studies; 166 had no named family established. The unspecified-family label occurs in 170 studies because it can co-occur with a named family.

SENSITIVITY_EXACT_IDENTIFIER_CORRECTED_MODEL_FAMILIES_N470.csv supplies the current 470-study model sensitivity. Pre-audit model-family rows for the 464-study preprint/repository sensitivity are excluded because they were not separately re-audited.

TABLE_1_SELECTION_AGREEMENT_HUMAN_AUDIT.csv contains the selection and original model-review agreement results. LEAD_AUTHOR_CHECKS_CURRENT_SEPARATE_STAGES.csv keeps later human-check stages separate. Full row-level human evidence is in Resource 6. The original August 85/100 concordance predates the Scopus extension and does not validate the final six-source corpus.

A blank, missing, uncertain or not-applicable value is not a zero. The 2026 count covers only through 13 August. Multiple-response categories need not sum to 483.
