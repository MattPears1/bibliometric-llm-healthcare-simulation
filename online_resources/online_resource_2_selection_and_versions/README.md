# Online Resource 2: selection, model review, and publication versions

This folder documents the complete selection and resolution workflow:

- `SUPPLEMENT_SELECTION_FLOW_COMPLETE.*`: retrieval, duplicate handling, candidate screening, resolution, eligibility, and study consolidation;
- `SUPPLEMENT_MODEL_REVIEW_CONFUSION_MATRICES.*`: three-choice and binary model-stream comparisons;
- `SUPPLEMENT_LEAD_AUTHOR_OVERSIGHT_AUDIT_V5.*`: the deliberately stratified 100-record oversight exercise, reported as concordance rather than accuracy;
- `PUBLICATION_VERSION_LEDGER_REDUCED.csv`: 547 eligible publication records with restricted title, author, abstract, and full-text fields removed; and
- `PUBLICATION_VERSION_FAMILY_SUMMARY.csv`: one row for each of 485 canonical studies.

The 547 eligible publication records include 62 alternate versions. One preferred publication represents each study in the analysis.
