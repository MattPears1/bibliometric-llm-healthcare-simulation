# Online Resource 2. Selection and publication versions

COMPLETE_RECORD_LEVEL_SELECTION_LEDGER_N3919.csv contains all 3,919 reviewed records, paired decisions, criteria, final eligibility decisions and resolution flags. ELIGIBLE_PUBLICATION_VERSION_LEDGER_N547.csv contains all 547 eligible publication records, preferred-publication flags and family relationships. There are 483 preferred records and 64 alternate versions.

SELECTION_FLOW_COMPLETE.csv supplies the complete stage counts. The screening codebook, response schema, batch manifest and two comparison manifests document the review process. Both review streams applied the same codebook.

The paired record-level decisions yield 477 direct INCLUDE/EXCLUDE disagreements, 551 three-choice disagreements and 501 binary include/non-include disagreements. These are different measures.

PUBLIC_EXPORT_NOTES.json documents omitted free-text source quotations and two fields containing incidental contact details or descriptive text supplied as a title. Scientific decisions and record identifiers are unchanged. Historic screening-stage classification fields are not the current model-family audit; use Resource 5 for current study-level labels.

Absolute private paths in manifests have been replaced by controlled-source basenames. Original source hashes are retained. Those manifests are provenance and do not imply that restricted raw inputs are distributed.

Two provider title fields concatenated the titles of every conference session; the public export retains the conference collection title. Their identifiers and exclusion decisions are unchanged, and the original values remain in the hash-recorded private source.
