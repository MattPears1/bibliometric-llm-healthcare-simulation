# Online Resource 5: checked one-study dataset and dictionary

`ONLINE_RESOURCE_5_CHECKED_ONE_STUDY_DATASET.csv` contains 485 rows, one preferred publication per included study, with stable identifiers, corrected bibliographic audit fields, checked model/simulation/NTS/specialty/design classifications, evidence URLs, and extraction provenance.

`ONLINE_RESOURCE_5_DATA_DICTIONARY.csv` defines all 23 public fields.

Abstract text, raw API payloads, full text, and restricted provider metadata are not redistributed in this reduced dataset.
