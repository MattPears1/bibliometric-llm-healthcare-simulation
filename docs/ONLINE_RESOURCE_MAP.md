# Online Resource map

The manuscript cites five Online Resource groups. This repository mirrors that numbering exactly.

| Manuscript resource | Repository folder | Contents |
|---|---|---|
| Online Resource 1 | `online_resources/online_resource_1_search_strategy/` | The 18 exact queries, dates, fields, pagination counts, completion states, and source-file hashes. |
| Online Resource 2 | `online_resources/online_resource_2_selection_and_versions/` | Complete selection flow, model-review confusion matrices, the lead-author oversight summary, 485-family summary, and 547-publication reduced version ledger. |
| Online Resource 3 | `online_resources/online_resource_3_complete_results/` | Complete annual, source, access, citation, author, geography, model, simulation, NTS, design, specialty, missingness, and sensitivity outputs. |
| Online Resource 4 | `online_resources/online_resource_4_phrases/` | The 34 predefined phrase groups and variants, full phrase counts, per-study indicators, co-occurrence data, network ledgers, and the conditional phrase network. |
| Online Resource 5 | `online_resources/online_resource_5_reduced_dataset/` | The checked 485-study public dataset and its 23-field data dictionary. |

Main publication tables and figures are duplicated under `results/` for convenient journal upload. Release-wide controls are at the repository root and under `audit/`.
